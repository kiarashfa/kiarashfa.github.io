# KiarashFa

**KiarashFa** is my landing site: everything I make, in one place. Each project has a page of its own with the idea behind it, the story of how it began, the challenges I solved along the way, and a way into the project itself.

The whole site is cast in liquid mercury, rendered live in the browser: the name of each project rides two drops that fuse and pour into its own emblem.
